when we have two terms which are grouped together? Is there a way to simplify the expressions? These two formulae are known as the *Double Angle Formulae* and are as follows. \ >:::: {.the data-latex=""} ::: {.proposition name="Double Angle Formulae"} \ For an angle $A$, we have that \ $$sin(2A) = 2sin(A)cos(A)$$ \ $$cos(2A) = cos^2(A) - sin^2(A)$$ ::: \ There is no need to know where these formulae come from, but we will now briefly see how we can obtain these two equations from the formulae for compound angles. \ >:::: {.the data-latex=""} ::: {.proof} \ We are goimg to use the formulae from the compound angle section to prove these formulae. We do this by setting $$b=a$$. Then, we have that the formulae are \ $sin(A+A) = sin(A)cos(A) + cos(A)sin(A)$ \ $cos(A+A) = cos(A)cos(A) - sin(A)sin(A)$ \ We can see that the first formula simplifies to \ $sin(2A) = 2sin(A)cos(A)$ \ as $sin(A)cos(A)=cos(A)sin(A)$ \ and the second formula simplifies to \ $cos(2A) = cos^2(A) - sin^2(A)$ \ giving our two equations. ::: Now that we've seen what these formulae involve, let's look at how we can use them in some examples. >:::: {.exa data-latex=""} :::{.example} \ Simplify $sin(2*60)$. \ \ We use the first of the two double angle formulae \ $$sin(2A) = 2sin(A)cos(A)$$ to get that $$sin(2x60) = 2sin(60)cos(60)$$ which is equal to $$2* \frac{\sqrt{3}}{2}*\frac{1}{2} = frac{\sqrt{3}}{2}$$ giving our final answer. \ ::: >:::: {.exa data-latex=""} :::{.example} \ Simplify $cos(90)$. \ \ Normally, this identity can be easily remembered anyway, or worked out by looking at a cos graph and finding the point on the graph where $cos(90)$ intersects the y-axis. However, these double angle formulae give another way of working it out. \ We use the second of the two double angle formulae \ $$cos(2A) = cos^2(A) - sin^2(A)$$ We start by setting $2A=90$ so that we can use our formula, giving $A=45$. Then $$cos(2*45) = cos^2(45) - sin^2(45)$$ In this case, $cos(45) = sin(45) = \frac{1}{\sqrt{2}}$ so $$cos^2(45) = sin^2(45) = \frac{1}{2}$$ Using this in our formula gives us that $$cos(2*45) = cos^2(45) - sin^2(45) = \frac{1}{2} - \frac{1}{2} = 0$$ and so our final answer is just 0 \ ::: ## Proving Trig Identities One of the main parts of this trig section is about proving trig identities. \ We have already seen some trig identities in the AS part of this course, and we will now move on to examine some more identities and prove these identities using formulae we already know. We'll also look at some more complex identities and see how we can prove them. \ \ There are 5 main formulae which we have learned about so far, and these 5 formulae will be the key to proving pretty much all of our trig identities. These are: \ \ $sin^2x + cos^2x = 1$ \ $\frac{sinx}{cosx} = tan{x}$ \ Our inverse trig identities, $\frac{1}{sinx} = cosecx$ \ $\frac{1}{cosx} = secx$ \ $\frac{1}{tanx} = cotx$ \ $sec^2(x) = 1 + tan^2(x)$ \ $cosec^2(x) = 1 + cot^2(x)$ \ \ Let's see some examples of identities which we can prove using these. >:::: {.the data-latex=""} ::: {.proposition} \ \begin{equation*} cot(x) = \frac {cos(x)}{sin(x)} \end{equation*} ::: \ >:::: {.pro data-latex=""} ::: {.proof} \ The function $tan(x)$ can be written as \begin{equation*} \frac {sin(x)}{cos(x)} \end{equation*} and we also know that $cot(x)$ is equal to \begin{equation*} \frac {1}{tan(x)} \end{equation*} ::: This is the very basic idea of proof: We look at a statement and keep changing it using formulae until it matches the statement we know is true from a trig identity. \ Let's have a look at a more difficult one. \ >:::: {.exa data-latex=""} ::: {.example} \ Prove that $${cot(x)}{sin(x)} = cos(x) + cos(x)cot^2(x)$$ ::: \ >:::: {.pro data-latex=""} :::{.proof} \ The idea of most of these proofs is to break down the reciprocal trig ratios and $tan(x)$ terms into $sin(x)$ and $cos(x)$ terms. \ \ We start off by writing all of the reciprocal trig ratios in terms of $sin(x)$, $cos(x)$ and $tan(x)$. This is usually the first step to proving any of these trig identities. \ Using the fact that $cot(x) = \frac{1}{tan(x)}$, and equivalently, $cot^2(x) = \frac{1}{tan^2(x)}$, $${cot(x)}{sin(x)} = cos(x) + cos(x)cot^2(x)$$ can be written as $$\frac{sin(x)}{tan(x)} = cos(x) + \frac{cos(x)}{tan^2(x)}$$ Then, we use the identity $$tan(x) = \frac{sin(x)}{cos(x)}$$ to split $tan(x)$ into the $sin(x)$ and $cos(x)$ components. This gives us $$\frac{cos(x)}{sin^2(x)} = cos(x) + \frac{cos^3(x)}{sin^2(x)}$$ Notice that there is a common $cos(x)$ term in all of the variables. We can divide this equation by $cos(x)$ to get $$\frac{1}{sin^2(x)} = 1 + \frac{cos^2(x)}{sin^2(x)}$$ which we know is true because is it just the same as $$cosec^2(x) = 1 + cot^2(x)$$ using the reciprocal trig ratios which we know, and this equation is one of the trig identities which we have learned. e^{-2ix} - 2) + \frac{1}{4}(e^{2ix} + e^{-2ix} + 2) = $\frac{1}{4}(4) = 1 $$ ::: ## Harmonic Form ### Converting to Harmonic Form We've seen one way to expand one trigonometric function into two functions, but how can we simplify two terms into one term? \ \ A method we can use to simplify equations with two different trig terms is writing it in **Harmonic Form** \ \ >:::: {.the data-latex=""} ::: {.theorem name="Harmonic Form"} \ If $x$ is an angle, then \ $asin(x) + bcos(x) = rsin(x + a)$ \ where $a = tan~^-1~(\frac{b}{a})$ \ and \ r = \sqrt($a^2+b^2$) ::: \ We don't need to know how to prove this, but the proof can be found in the extra material section. \ \ Let's look at a few examples of how to put this idea into practice. \ >:::: {.exa data-latex=""} ::: {.example} \ Simplify $3sin(x) + 4cos(x)$ \ \ We start by calculating the values of $r$ and $a$. \ \ $r =$ \sqrt($a^2+b^2$) so $r =$ \sqrt($3^2+4^2$) = \sqrt($9+16$) = \sqrt(25) $= 5$ \ $a = tan~^-1~(\frac{b}{a}) = tan~^-1~(\frac{4}{3}) = 53.1$ \ \ This gives the result that $$3sin(x) + 4cos(x) = 5sin(x + 53.1)$$ ::: >:::: {.exa data-latex=""} ::: {.example} \ Simplify $12sin(x) + 5cos(x)$ \ \ We start by calculating the values of $r$ and $a$. \ \ $r =$ \sqrt($a^2+b^2$) so $r =$ \sqrt($12^2+5^2$) = \sqrt($144+25$) = \sqrt(169) $= 13$ \ $a = tan~^-1~(\frac{b}{a}) = tan~^-1~(\frac{5}{12}) = 22.6$ \ \ This gives the result that $$12sin(x) + 5cos(x) = 13sin(x + 22.6)$$ ::: >:::: {.exa data-latex=""} ::: {.example} \ Simplify $3sin(x) - 2cos(x)$ \ This looks like it might be more complicated because we now have a $-$ sign involved, but actually the procedure is still the same. \ We still square and add the $3$ and the $-2$ and, which is just the same as squaring and adding $3$ and $2$ (as the square of the positive and negative version of the number is just the same e.g. $1^2 = 1 and -1^2 = 1$). \ We also do the same thing with finding the angle using $tan^{-1}$ but have to be careful to remember to include the $-$ sign in the fraction. \ \ We start by calculating the values of $r$ and $a$. \ \ $r =$ \sqrt($a^2+b^2$) so $r =$ \sqrt($3^2+4^2$) = \sqrt($9+4$) = \sqrt(13) \ $a = tan~^-1~(\frac{b}{a}) = tan~^-1~(\frac{-2}{3}) = -33.69$ \ \ This gives the result that $$3sin(x) - 2cos(x) = \sqrt(13) sin(x - 33.69)$$ ::: ### Solving Equations using Harmonic Form We can also use this idea to solve equations, which may seem complicated at first, but when we apply this idea, can make a lot simpler. >:::: {.exa data-latex=""} ::: {.example} \ Solve $12sin(x) + 5cos(x) = 4$ \ \ The left hand side is the same as the example which we saw before, but this time, we need to solve an equation not just find an expression for something. We start the same way as before to reach the same point: \ \ $r =$ \sqrt($a^2+b^2$) so $r =$ \sqrt($12^2+5^2$) = \sqrt($144+25$) = \sqrt(169) $= 13$ \ $a = tan~^-1~(\frac{b}{a}) = tan~^-1~(\frac{5}{12}) = 22.6$ \ \ So $$12sin(x) + 5cos(x) = 13sin(x + 22.6)$$ as before. \ \ Then, we pop in the new expression we've found for the left-hand side in place of the old one to get $$13sin(x + 22.6) = 4$$ We are then looking to solve this equation by finding $x$. We do this by making it the subject of the formula, by rearranging. Initially, this makes the equation $$sin(x + 22.6) = \frac{4}{13}$$ Then, we use $sin^{-1}$ to get $$x + 22.6 = sin^{-1} ( \frac{4}{13})$$ which gives us $$x + 22.6 = 17.1$$ and then we find that taking 22.6 over to the other side gives $$x = 17.1 - 22.6$$ so $$x=-5.5$$ :::
